# 動画の品質チェック（公開前）

自動で確認できる項目は `node tools/qa.mjs` で、静止画での目視は `node tools/qa.mjs --stills` で行う（`video/` で実行）。
参考にした考え方：video-shotcraft（Apache-2.0）の品質基準（静止・加速度・ペース・音）。コードや音源は取り込んでいない。

## 自動（`node tools/qa.mjs`）
- [ ] 解像度 1080x1920、30fps
- [ ] フレーム数が `src/timing.json` と一致
- [ ] 音声ストリームがある。映像と音声の長さが一致
- [ ] 長さが 90 秒以内
- [ ] 読みの一覧（`docs/narration-readings.md`）が最新

## 目視（`--stills` の静止画）
- [ ] 文字が重なっていない。画面の端で切れていない
- [ ] 字幕・カードの改行が、文節の切れ目になっている（単語の途中で切れていない）
- [ ] 重要な情報（年月日・結論）が出たあと、約1秒は静止している（場面の終わり `*-end.png` が、情報が出そろった状態になっている）
- [ ] 図・タグ（一次史料／諸説／伝承）が、台本の信頼度と一致している
- [ ] 画面下の出典表示がある

## 聴いて確認（人間のみ）
- [ ] 読み間違い・アクセントの違和感がない（`docs/narration-readings.md` と見比べる）
- [ ] ナレーションが聞き取れる。BGM が声を邪魔していない
- [ ] 効果音が大きすぎない。場面の切り替えで、音が途切れたり重なったりしない

## 公開前のゲート（人間）
- [ ] 台本の事実確認（`docs/episode-*.md` の「公開前の確認事項」）
- [ ] クレジット（`docs/credits.md`）を、概要欄に転記した
- [ ] 各プラットフォームの AI 生成コンテンツの表示ルールを満たした
